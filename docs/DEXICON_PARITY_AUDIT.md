lines) and `atomix-ui.css` against `renderer/dexicon-ax.js`; `renderer/pools.js` (875 lines), `pools.css` and
`poolcalc.js` against `renderer/dexicon-pp.js`; with `dexicon-ui.js`, `dexicon-core.js`, `dexicon.css` and the shared
parts of `app.js` for both. Nothing was run on a node. Line numbers are those of 0.18.140 (commit 754e506); old-panel
lines can be read with `git show 754e506:renderer/atomix-ui.js` and `git show 754e506:renderer/pools.js`.

Status words: SAME, MOVED (same thing, another place), CHANGED (a user could notice a difference; how is said),
NOT FOUND (no equivalent), RESTORED (was lost or changed, put back in 0.18.141).

1. **OTC Withdraw is always there** (AtomiX row 98). It had been drawn only while the screen believed the offer was
   live; an offer still on the board could then not be withdrawn from the screen.
2. **A failed "Check for reserves" keeps its message** (Pools row 25). It was erased in the same click.
3. **The Swap quote is asked again when the pools move** (Pools row 112), as the old panel did on every engine update.
4. **The K/KMIN number** beside "healthy / migrate soon" (Pools row 105).
5. **"Stop every other copy of this wallet that signs"** on the paused-signing card (Pools row 64).
6. **"Building the statement…"** while the statement is built (Pools row 116).
7. **The chart follows a theme change at once** (AtomiX row 12).
8. **A Daylight user of the old AtomiX panel opens Dexicon in its light theme** (AtomiX row 11).
9. **The fonts.** The only `@font-face` rules for Inter and JetBrains Mono were in `atomix-ui.css`; all three rooms
   are drawn in them. They are in `dexicon.css` now. Not a feature of the old panel, but it would have gone with it.

## The reported mismatch of `main/atomix/lib/maker.js` with its donor

It was real when reported and is gone. The donor (`mds/atomix-mds`) moved from 0.1.57 to 0.1.59 and 0.1.60 (the
market editor's spread, then randomised sizes): `lib/maker.js` gained `spread, rand, randSeed` in the saved config and
`lib/peg.js` the code that applies them, while the desktop's copy was still 0.1.57. 0.18.130 copied both files again
(with the engine's other changes of that step). Today `bash scripts/atomix-parity-check.sh` reports
"40 engine files byte-identical to the donor", the donor's working tree is clean for these files, and its HEAD is
03d56652cd55ff68f4dd2de4e8d4a1d15aff1315 (atomix-mds 0.1.60). No vendored file was edited by hand.
